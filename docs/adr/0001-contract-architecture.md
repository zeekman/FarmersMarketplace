# ADR 0001: Contract Architecture (superseded)

- **Status:** Superseded by [ADR 0002: Contract Architecture](0002-contract-architecture.md)
- **Date:** 2024-02-01

This document was merged with the crate-boundary ADR because both proposed an
ADR 0001 with conflicting decisions. The accepted decision — a single
`=22.0.0` SDK pin, deferred shared crate, 500 bps fee cap and legacy contract
deprecation — is recorded in
[ADR 0002](0002-contract-architecture.md). See also
[ADR 0001: Soroban Contract Crate Boundaries](0001-soroban-contract-boundaries.md)
for the historical convention.
