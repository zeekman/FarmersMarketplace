# Implementation Notes (Archive)

This folder holds historical write-ups produced alongside past feature and
bugfix branches — design decisions, task checklists, and testing/validation
notes captured at the time the work was done.

They're kept for reference (searchable history of *why* a change was made),
but they are **not** living documentation and are not guaranteed to reflect
the current state of the code. For current, maintained documentation see:

- [`README.md`](../../README.md) — project overview and setup
- [`CONTRIBUTING.md`](../../CONTRIBUTING.md) — contribution guidelines
- [`docs/adr/`](../adr/) — architecture decision records
- [`docs/deployment.md`](../deployment.md), [`docs/escrow-migration-runbook.md`](../escrow-migration-runbook.md)

These files previously lived at the repository root (and a few under
`backend/`); they were moved here to keep the root directory focused on
entry-point docs (`README.md`, `CONTRIBUTING.md`).
